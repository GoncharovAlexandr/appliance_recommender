# Рекомендательная система для подбора бытовой техники

## 1. О проекте

Проект представляет собой рекомендательную систему для подбора бытовой техники на основе предпочтений пользователей.

Система анализирует оценки товаров и рекомендует пользователю технику, которая может ему понравиться.

## 2. Используемые технологии

- **Python** — основной язык программирования.
- **Streamlit** — пользовательский веб-интерфейс.
- **Pandas** — обработка и анализ данных.
- **NumPy** — математические вычисления.
- **SciPy** — работа с разреженными матрицами.
- **Scikit-learn** — вычисление косинусного сходства пользователей.

## 3. Алгоритм рекомендаций

Используется метод **User-Based Collaborative Filtering** (коллаборативная фильтрация на основе пользователей).

Основные этапы:
1. Загрузка информации о товарах и пользовательских оценок из CSV-файлов.
2. Формирование матрицы предпочтений пользователей.
3. Вычисление сходства пользователей с помощью косинусного сходства.
4. Поиск пользователей с похожими предпочтениями.
5. Прогнозирование оценок товаров.
6. Формирование персональных рекомендаций.

Для новых пользователей, у которых ещё нет оценок, предусмотрена рекомендация популярных товаров.

## 5. Возможности приложения

- Просмотр каталога бытовой техники.
- Фильтрация товаров по категориям.
- Фильтрация по стоимости.
- Получение персональных рекомендаций.
- Просмотр прогнозируемой оценки товара.
- Добавление пользовательских оценок от 1 до 5.
- Сохранение оценок в CSV-файл.
- Рекомендации популярных товаров для новых пользователей.

## 6. Установка и запуск

### Создание виртуального окружения

```bash
python -m venv .venv
```

### Активация окружения

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

### Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### Запуск приложения

```bash
streamlit run app.py
```

После запуска приложение откроется в браузере.

## 7. Тестирование

Для запуска автоматических тестов:

```bash
python test_recommender.py
```

Для оценки качества рекомендательного алгоритма:

```bash
python evaluate.py
```

## 8. Результаты оценки алгоритма

Для проверки качества использовалось разделение данных на обучающую и тестовую выборки.

| Показатель | Результат |
|---|---:|
| Обучающие оценки | 40 |
| Тестовые оценки | 8 |
| MAE | 0.7500 |
| RMSE | 0.8944 |

**MAE** показывает среднюю абсолютную ошибку прогнозирования.

**RMSE** показывает среднеквадратичную ошибку и сильнее учитывает большие отклонения.

Результаты являются предварительными, поскольку использовался небольшой набор данных.

## 9. Данные проекта

Файл `products.csv` содержит информацию о бытовой технике:
- идентификатор товара;
- название;
- категория;
- производитель;
- цена;
- описание;
- характеристики.

Файл `ratings.csv` содержит пользовательские оценки:
- идентификатор пользователя;
- идентификатор товара;
- оценка от 1 до 5.
