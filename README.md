# Рекомендательная система для подбора бытовой техники

## 1. О проекте

Проект представляет собой рекомендательную систему для подбора бытовой техники на основе предпочтений пользователей.

Система анализирует оценки товаров и рекомендует пользователю технику, которая может ему понравиться.

## 2. Используемые технологии

- **Python** — основной язык программирования.
- **Streamlit** — пользовательский веб-интерфейс.
- **Pandas** — обработка и анализ данных.
- **NumPy** — математические вычисления.
- **SciPy** — работа с разреженными матрицами.
- **Scikit-learn** — вычисление косинусного сходства пользователей.

## 3. Алгоритм рекомендаций

Используется метод **User-Based Collaborative Filtering** (коллаборативная фильтрация на основе пользователей).

Основные этапы:
1. Загрузка информации о товарах и пользовательских оценок из CSV-файлов.
2. Формирование матрицы предпочтений пользователей.
3. Вычисление центрированного косинусного сходства по общим товарам с учётом количества общих оценок.
4. Поиск похожих пользователей, оценивших рассматриваемый товар.
5. Прогнозирование оценок с учётом среднего рейтинга товара, предпочтений пользователя и оценок соседей.
6. Формирование персональных рекомендаций.

Для новых пользователей товары сортируются по среднему рейтингу; количество оценок учитывается при равенстве рейтинга.

Формулы, условия холодного старта и ограничения описаны в [docs/recommendation.md](docs/recommendation.md).

## 5. Возможности приложения

- Просмотр каталога бытовой техники.
- Поиск по названию и бренду, фильтрация по категориям и стоимости.
- Получение персональных рекомендаций.
- Просмотр прогнозируемой оценки товара.
- Создание локального профиля и выставление оценок от 1 до 5 на карточках товаров.
- Сохранение оценок в CSV-файл.
- Постраничный просмотр рекомендаций и подбор по средним оценкам для новых пользователей.

## 6. Установка и запуск

### Создание виртуального окружения

```bash
python -m venv .venv
```

### Активация окружения

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows:

```bash
.venv\Scripts\activate
```

### Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### Запуск приложения

```bash
streamlit run app.py
```

После запуска приложение откроется в браузере.

## 7. Тестирование

Для запуска автоматических тестов:

```bash
python test_recommender.py
```

Для повторяемого сравнения алгоритма с прогнозом по среднему рейтингу товара:

```bash
python evaluate.py
```

По умолчанию используются фиксированный демонстрационный набор из `data/experiment/ratings_demo.csv`, 10 разбиений и начальное значение 42. Рабочие оценки в приложении на результаты этого эксперимента не влияют. Другой набор и параметры можно указать явно:

```bash
python evaluate.py --ratings data/ratings.csv --runs 20 --seed 42
```

Для отдельного синтетического набора из 200 пользователей используйте:

```bash
python evaluate.py --ratings data/experiment/ratings_synthetic.csv
```

Чтобы сравнить прежний и текущий варианты на одинаковых разбиениях и дополнительно проверить попадание отложенных высоких оценок в топ-3, запустите:

```bash
python evaluate.py --ratings data/experiment/ratings_synthetic.csv --seed 100 --model legacy --ranking
python evaluate.py --ratings data/experiment/ratings_synthetic.csv --seed 100 --model current --ranking
```

Набор создан скриптом `generate_experiment_data.py` с `--seed 2026`. Он моделирует предпочтения по категориям и брендам, индивидуальную склонность ставить высокие или низкие оценки и случайный шум. Каждый пользователь оценивает от 3 до 8 товаров. Данные искусственные и зависят от этих предположений; успешный результат на них не доказывает качество на реальных людях. Генератор не меняет рабочие оценки и отказывается перезаписывать существующий файл; для нового набора укажите другой путь, например:

```bash
python generate_experiment_data.py --users 300 --seed 10 --output data/experiment/ratings_variant.csv
```

## 8. Результаты оценки алгоритма

Для каждого разбиения у каждого пользователя с двумя и более оценками часть оценок откладывается для проверки, а остальные используются для обучения. Средний рейтинг товара для базового прогноза вычисляется только по обучающей выборке; если оценок товара в ней нет, используется общее среднее. В отчёте приведены средние MAE и RMSE, диапазон результатов и доля прогнозов, рассчитанных по оценкам похожих пользователей.

**MAE** показывает среднюю абсолютную ошибку прогнозирования.

**RMSE** показывает среднеквадратичную ошибку и сильнее учитывает большие отклонения.

Разбиения пересекаются, поэтому результаты не являются независимыми экспериментами. Исходные данные искусственные и очень малочисленные; результаты не доказывают качество на реальных пользователях. Метрика топ-3 рассчитывается только при параметре `--ranking` и является приближением: оценки доступны лишь для части товаров. В эксперименте и приложении используется общий метод прогнозирования.

Профили сохраняются в `data/users.json` и работают локально без авторизации. CSV-хранилище предназначено для учебного использования и не рассчитано на одновременную запись несколькими пользователями.

## 9. Данные проекта

Файл `products.csv` содержит информацию о бытовой технике:
- идентификатор товара;
- название;
- категория;
- производитель;
- цена;
- описание;
- характеристики.

Файл `ratings.csv` содержит пользовательские оценки:
- идентификатор пользователя;
- идентификатор товара;
- оценка от 1 до 5.
