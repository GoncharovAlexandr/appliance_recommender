# Сравнение алгоритмов на синтетических данных

Ниже — воспроизводимый учебный эксперимент, а не оценка работы с реальными покупателями. Синтетический набор сформирован генератором проекта с seed 2026, 200 пользователями и 12 товарами. Оценки содержат искусственно заданные предпочтения по категориям и брендам, индивидуальное смещение и случайный шум. Пропуски также создаются по правилам генератора.

На одинаковых 10 разбиениях с начальными seed 100–109 (по 200 отложенных оценок) получены:

| Показатель | Прежний алгоритм | Текущий алгоритм | Среднее товара |
|---|---:|---:|---:|
| Средний MAE | 1,0675 | 0,8862 | 0,9474 |
| Средний RMSE | 1,3137 | 1,0889 | 1,1317 |
| Прогнозы по похожим пользователям | 63,9% | 93,0% | — |
| Попадание высоко оценённого товара в топ-3 | 46,5% | 50,0% | 43,2% |

Каждое разбиение содержит тех же пользователей, поэтому доли и средние не следует рассматривать как результаты независимых наблюдений. Метрика топ-3 рассчитана на 1057 случаях «пользователь × разбиение» с отложенной оценкой 4 или 5. Она сравнивает ранжирование среди товаров, не попавших в обучение, и не учитывает неизвестные истинные оценки этих товаров.

Проверены также два других набора, созданных тем же генератором с seed 2040 и 2041. Средний MAE текущего алгоритма составил соответственно 0,9021 и 0,8544, а среднего товара — 0,9518 и 0,9295. При этом на исходном наборе из 8 пользователей новая модель на части разбиений уступает прежней; например, при seed 100–109 средний MAE составил 0,8229 против 0,6348 у прежней модели. Этот набор слишком мал для устойчивого выбора алгоритма.

Параметры новой модели подбирались с учётом других искусственных наборов из того же генератора. Поэтому даже проверка на новых seed не подтверждает качество для иной модели поведения или реальных пользователей. Данных реальных покупателей и отдельного внешнего тестового набора в проекте нет.

Команды воспроизведения:

```bash
python evaluate.py --ratings data/experiment/ratings_synthetic.csv --seed 100 --model legacy --ranking
python evaluate.py --ratings data/experiment/ratings_synthetic.csv --seed 100 --model current --ranking
python generate_experiment_data.py --seed 2040 --output /tmp/hometech_new_2040.csv
python evaluate.py --ratings /tmp/hometech_new_2040.csv --seed 100 --model current
```

Генератор не перезаписывает существующий файл. Для повторного создания набора выберите другой путь.
